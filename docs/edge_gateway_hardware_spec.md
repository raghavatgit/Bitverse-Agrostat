# ESP32-S3 Agrostat Gateway Hardware Specification

## Microcontroller
- SoC: Espressif ESP32-S3 (Xtensa Dual-Core 32-bit LX7, 240 MHz)
- SRAM: 512 KB internal + 8 MB Octal PSRAM
- Flash: 16 MB Quad SPI

## Radio Subsystems
- LoRa Transceiver: Semtech SX1262 (SPI interface, +22 dBm PA)
- Cellular Fallback: SIM7080G Cat-M/NB-IoT (UART interface)
